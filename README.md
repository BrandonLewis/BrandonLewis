# Brandon Lewis

Twenty-eight years in heavy civil construction, from carpenter foreman on bridges and
flood control to estimator and project manager. Since 2025 I have been building the
software that lets people and AI agents work with what used to be locked in PDFs,
spreadsheets and proprietary formats.

## What I'm building

| | |
|---|---|
| [ProjectCommand](https://github.com/BrandonLewis/projectcommand-releases) | IFC-native project management for heavy civil. Joins model, schedule and cost per element, with 3D and 4D playback. Desktop app for Windows and macOS. Rust, WebAssembly, TypeScript. |
| [Conformed.ai](https://conformed.ai) | Conformed plans and specs for every addendum, and answers from the plan set, with an evaluation harness in CI. |
| [bimforge](https://github.com/BrandonLewis/BIMForge) | IFC-native CAD/BIM toolkit: plan sheets to parametric IFC to quantities to 4D/5D. `pip install bimforge` |
| [BidSheet.ai](https://www.bidsheet.ai) | Bid management for contractors, with an MCP server so an agent can work an estimate. |
| [estimating-tools](https://github.com/BrandonLewis/estimating-tools) | Construction estimating for agents: an open data model, command-line tools, agent skills and MCP servers. |
| [django-mcp-oauth](https://github.com/BrandonLewis/django-mcp-oauth) | OAuth 2.1 authorization server for MCP resource servers, as a Django app. Built on Authlib. |
| [judgeswap](https://github.com/BrandonLewis/judgeswap) | Position-swapped LLM-as-judge, regression floors and an embedding A/B scorer, with the negative results written up. |

## Earlier open-source work

My first GitHub contributions, from 2010 to 2012, were to the Arizona and Idaho legislature
scrapers for the Sunlight Foundation's Fifty State Project, now [Open States](https://github.com/openstates/openstates-scrapers):
bills, votes, committees, legislators and committee agendas (89 commits).

Built with agents, behind tests and evaluation harnesses. Based in Northern California.
